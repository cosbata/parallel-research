# Research workflow

## Core objects

| Object | Role |
| --- | --- |
| Research question | Starts the investigation and gives each lane shared context. |
| Parallel lane | Explores one distinct angle without overwriting the others. |
| Source material | Preserves the evidence collected by a lane. |
| Synthesis | Connects the conclusion back to the lanes and material it uses. |
| Follow-up research | Extends a useful lane or challenges a conclusion. |

## Design decisions

- **Preserve the path, not only the answer.** A synthesis should be inspectable after it is written.
- **Keep lanes independent.** Different research directions should remain comparable instead of collapsing into one chat stream.
- **Treat sources as product data.** Sources are not decorative citations; they are the route back to evidence.
- **Keep the production system private.** This repository shows the product and technical thinking without exposing credentials, user work, or operating details.
